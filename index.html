Como usar este plano

  1. Abra um módulo clicando no cabeçalho do cartão — ele expande para mostrar as aulas.
  2. Marque cada aula ao concluir, usando a caixinha à esquerda do título.
  3. Complete o checkpoint ao final de cada módulo antes de seguir para o próximo — o módulo seguinte só destrava quando o anterior estiver 100% concluído.

Seu progresso é salvo automaticamente no navegador (localStorage). Se limpar os dados do site ou trocar de dispositivo, a trilha reinicia do zero.
